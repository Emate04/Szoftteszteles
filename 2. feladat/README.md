# Arab → Római Szám Konverter (TDD)

Ez a projekt egy JavaScript nyelven íródott konverter, amely az arab számokat (1–3999) alakítja át római számokká a Test Driven Development (TDD) módszertant követve.

## Használt technológiák
- **Nyelv:** JavaScript (ES6+)
- **Tesztkeretrendszer:** QUnit 2.x
- **Verziókezelés:** Git & GitHub
